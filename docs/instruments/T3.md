# T3 instruments

Phase 11, workstream E ([docs/12-phase-11.md](../12-phase-11.md)). Three instruments against `IInstrument`, in
`Anode.Dsp`, after the T2 structure ([T2.md](T2.md)): a public sealed class wrapping a private
`PolyInstrument<TVoice>` engine (sample-accurate events, the 16-sample control grid, voice stealing with a 5 ms fade,
pedal, wheel, bend, CC 120/121/123), parameters through `ParameterBank`/`ParameterList`, state through
`InstrumentState` (`ANIS`, by id), each voice on its own grid from its start, so a note sounds the same wherever it
falls and whatever the buffer size (tested to the bit). They are registered in `BuiltinInstruments`
and held to `InstrumentContractTests`.

| Id | Name | Voices | Loads | Design |
|---|---|---:|---|---|

## Physical Model

- **Modes.** Mode n is the note's frequency times the object's ratio: a string's n; a free bar's (β_n/β_1)² (β =
  1.506, 2.500, 3.500, then n + ½: 1, 2.757, 5.404, 8.933 …); a circular membrane's Bessel zeros over the first (1,
  1.593, 2.136, 2.295 …); an open tube's n, slightly flattened (end correction). Inharmonicity stretches mode n by
  √(1 + B(r_n² − 1)), B = 0.05·inharmonicity², so the first mode stays on the pitch. Modes at or above 0.45 of the rate
  are left out.
- **Material.** Damping sets the first mode's −60 dB time, 20 s at 0 % to 50 ms at 100 % exponentially
  (0.05 · 400^(1 − d)), times (261.6 Hz / f)^0.3 clamped to 0.5 … 1.6 (higher notes shorter). Stiffness sets how much
  faster higher modes die: T60_n = T60_1 · (1/r_n)^α, α = 1.5 (0 %, soft) … 0.2 (100 %, metal).
- **Shapes** (an exciter or a pickup at x, 0 … 1): sin(nπx) for string and tube, cos(nπx) for the free bar, a radial
  Bessel-like cos(π r_n x)(1 − x/2) for the membrane (an approximation of J_m). A pick at the middle of a string leaves
  its even modes still (tested).
- **Exciters.** Pick: each mode's displacement set to shape × 1/n through a plectrum low-pass whose corner rises with
  tone and velocity. Strike: shape through a steeper mallet low-pass (tone = hardness). Bow and blow are negative
  damping (as bow friction and a jet's feedback are): while the key or pedal holds the note, each mode is driven toward
  a target amplitude (shape × a bowed string's 1/n, or a flute's falling spectrum with odd modes stronger), regulated so
  it settles there, from a faint noise seed (10⁻⁴ of the target); the bow hair's and the breath's noise is added to the
  pickups (low-passed at 2.5 kHz, the breath 3×). The tone sets how fast they speak (150 … 25 ms) and the noise. Noise
  fed into the modes at audible level would make their phases, and so the pitch, wander (5–50 ct measured), which is
  why the texture noise bypasses them.
- **Body.** Three resonant bells per body (Guitar, Violin, Piano, Box; Off), at Body Amount, on the sum of the voices:
  linear and time-invariant from silence, so it does not change where a note falls; its denormals are flushed on the
  instrument's grid, not at buffer edges.
- A voice ends when its amp envelope does, or when no drive is left and every mode is below −110 dB.

## Tape Replay

- **Tape sets** (`TapeSet`, `Instruments/Tape/TapeSet.cs`): one mono recording per key from a first key, ≤ 8 s each,
  16-bit with a scale per key. File `.antape`, little-endian: `ANTP`, version (u16, 1), 16 reserved bits, sample rate
  (i32), first key and key count (a byte each), name (u16 length, UTF-8), then per key frames (i32), scale (f32) and the
  samples (i16). `TapeSet.From(name, rate, lowKey, recordings)` cuts each to 8 s; `ToBytes`, `Load`, `Read`.
- **The default set** (`TapeSet.Default`, generated once, 24 kHz, 35 keys G2–F5): a sawtooth doubled an octave below,
  low-passed, swelling in and fading.
- **Keys outside the set** play its nearest key octaves away, read faster or slower (in tune; the tape's time scales).
- **Length.** A held note stops when its tape runs out: 8 s at 100 % speed, plus half the start motor's time (the
  ramp from rest), with a 5 ms fade at the tape's end. A key played again starts its tape again (the old one fades as
  a stolen voice). Wow and flutter have their own phases per voice, seeded by the key, from the voice's start.
- **State:** the file's absolute path (as the samplers); a state without one plays the default set.

## Sample Alchemy

- **Analysis** (`AlchemySource`, off the audio thread at load, immutable; at most 60 s of the sample): the pitch is the
  median of pYIN's voiced frames (Phase 5's `PitchTracker`), moved by octaves toward a `smpl`/`INST` root note (which
  also sets `rootNote`); no voiced frame: the root note's pitch. Every 5.33 ms a 4,096-point Hann FFT (≈ 11.7 Hz bins
  at 48 kHz) is searched near each harmonic of the frame's pitch (±0.45 of it), refined by a log-magnitude parabola:
  64 partials a frame (amplitude, frequency over the first partial's amplitude-weighted mean, so the additive
  resynthesis lands on the key exactly). The spectral envelope: per frame each of 24 log-spaced bands' (60 Hz … 15 kHz)
  strongest component, smoothed 1-2-1.
- **Keys play their own pitch**: the sample's detected pitch is moved to the key's (the root note matters only for a
  sample with no pitch).
- **Granular** grains are placed pitch-synchronously: each starts within a period of where spray put it, where the
  sample's phase meets a steady tone's at the key's pitch, so a pitched sample's grains add up in phase instead of
  combing at the grain rate (without this the measured pitch was off by 10–140 ct).
- **AIFF**: `AiffReader` (new, `IO/AiffReader.cs`): AIFF and AIFF-C (`NONE`, `twos`, `sowt`, `fl32`, `fl64`), 8–32-bit,
  any channels, `INST` base note and detune.
- **State:** the file's absolute path; a state without one plays the default sample.

## Tape sets (content builder)

`engine/tools/Anode.ContentBuilder/TapeContent.cs` (`Ready` is true): strings (the physical model: bowed string,
violin body, vibrato), flutes (blown tube) and choir (Sample Alchemy's spectral mode on its "ah"), each key G2–F5 held
for 8 s, through a tape model (`anode.saturation`'s Tape model at 25 % drive and −25 % tone, a +2 dB head bump at
90 Hz, a one-pole replay-head loss at 9 kHz), decimated to 24 kHz (127-tap Blackman sinc), the last 60 ms faded, each
set brought to one peak. Each is `patches/tapes/<name>.antape` with an instrument patch `patches/tape_<name>.json`
(category "Tape Replay", `anode.tape-replay` with every parameter at its default and the set as its file, which the
server's patch library makes absolute where the pack is installed). The test pack has the strings over five keys
(G3–B3, 1.9 MB). Anode Essentials grows by three sets (≈ 40 MB; 72 s to build on a loaded machine). `PackBuilder`
gained `Asset(folder, name, bytes)` to write them.

## For the other workstreams

- **A (engine):** none needs `SetTransport`. `LoadFile` of the `.antape` / sample on the
  control thread; the loaded data are swapped by reference. Sample Alchemy's first instance builds its default
  analysis (≈ 0.1 s, once per process); Tape Replay's its default set (≈ 0.07 s, 13 MB, once).
- **B (server):** a Tape Replay patch's file is relative to its pack (as kits' samples). Sample Alchemy sets `rootNote`
  from a file's `smpl`/`INST` note.
- **C (editor):** custom panels: the physical model's object (`object`) and its exciters `exciter{n}Type`,
  `exciter{n}Position`, `exciter{n}Level`, `exciter{n}Tone` (n = 1 … 3) and pickups `pickup1Position`,
  `pickup2Position`, `pickupSpread` along it (positions 0 … 100 % of the object); `PhysicalModel.Ratio(kind, n, b)`
  and `Shape(kind, n, x)` are the modes and shapes to draw. Sample Alchemy's source view needs the file (`file`), its
  `mode`, `position`, `loopStart`, `loopEnd` (percent of the sample). The generic editor is enough for Tape Replay.
